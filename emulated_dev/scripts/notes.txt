VS Code Integration: Create tasks.json for build/run, and launch.json for debugging (attach to QEMU's gdb stub).

Resources: ARM Architecture Reference Manual (free from arm.com), Azeria Labs tutorials, or GitHub repos like ARMv8ViaLinuxCommandline.
